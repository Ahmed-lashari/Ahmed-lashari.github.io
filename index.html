Engineering Work

CNN-RNN OCR

Hybrid Deep Learning · Sequential Vision Modeling

A hybrid deep learning model engineered for recognizing noisy, handwritten medical prescriptions. Built by combining Convolutional Neural Networks (CNN) for spatial feature extraction with Recurrent Neural Networks (RNN) and CTC loss for sequence modeling.

Trained on a dataset of 77,000 unlabeled and 9,000 labeled prescription samples using transfer learning. The pipeline required building custom preprocessing, text line segmentation, and character-level evaluation from scratch rather than assembling off-the-shelf components.

Dataset: 86k total samples · Architecture: CNN + Bidirectional RNN · Transfer Learning Pipeline

Technical Focus

I build systems where language models do real work inside the core logic, not as a superficial chatbot widget, but as the computational processing engine for complex tasks that previously required manual human effort.

Most of that challenge revolves around retrieval and data infrastructure: how documents are intelligently parsed, chunked, and indexed; how retrieval relevance degrades under real-world noise; and how to engineer pipelines that perform deterministically on messy production data rather than pristine benchmarks.

I focus intensely on the boundary between where agentic systems deliver true reliability versus where they collapse, and architecting the resilient backend infrastructure that makes the difference between an ephemeral demo and a lasting product.

Currently

  • Expanding the INDUS.SYSTEMS product portfolio, additional proprietary AI platforms are currently in active design and prototyping.
  • Investigating the architectural boundaries of multi-agent state machines: identifying exact failure modes in multi-step agent reasoning and mitigating error cascading.
  • Local model deployment and private inference pipelines for enterprise domains with strict on-premises data residency requirements.
